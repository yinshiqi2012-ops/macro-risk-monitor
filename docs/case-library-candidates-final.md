# 案例库首期名单（已锁定）

> 状态：**已锁定，可进事件锚定流水线**。后续想到的标的再追加。
> 规则：一段 = 完整生命周期（牛+熊）；退市标的不计入；半程另册。

## 锁定决策

1. 你点名泡沫中 **可计算的 21 段全部进首期库**。
2. 退市/并购标的（Pets.com、Webvan、雅虎旧票、朗讯、贝尔斯登、雷曼、Countrywide）**不算段数**，不做计算。
3. 缺口用 **金银铜油碳酸锂** + **其他历史上大牛后泡沫破灭且周期已结束的品种** 补齐；你之后可继续添加。
