## 数据可获取性说明

- **A股/ETF/LOF/港股**：走 `ak_stock`/`ak_etf`/`ak_hk`，`akshare.stock_zh_a_hist_tx` 腾讯日线，前复权。老股票如贵州茅台 2001 年起可拉，2015 年代表股无问题。
- **美股**：走 `nasdaq`，api.nasdaq.com。历史深度通常可回 20+ 年，但部分股票代码会变（如 AIG 已大幅拆合股）。
- **商品期货**：走 `ak_futures`，新浪主连。白银、黄金、铜、原油主连可拉；碳酸锂期货需确认主连代码（如 `LC0` 或 `碳酸锂主连`）。
- **贵金属现货**：`ak_sge` 黄金 Au99.99 无量，主要用于对照。
- **BTC**：`okx` history-candles，2017 年后较完整；2015 段数据深度可能不足，需验证或换备用源。
