# 宏观及风险监控系统

跨品种（加密/商品/个股/指数）走势状态监控与机会/风险提示系统。
核心思想：**跨品种可比不靠绝对阈值，靠「品种自身 252 日滚动窗口分位数」归一化**——
BTC 的 RSI 80 和沪深300 的 RSI 80 含义不同，但「处于自身历史 95 分位」是可比的。

> **边界声明：本系统只做状态提示，不构成任何买卖建议，不给仓位/买卖点，不接实盘。**

## 用法

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python -m monitor.run                 # 生成当日报告 reports/YYYY-MM-DD.{md,html,pdf}
.venv/bin/python -m monitor.run --format html   # 只输出单一格式（md|html|pdf）
.venv/bin/python -m monitor.run --symbol BTC-USD  # 单品种详细读数（同样支持三格式）
.venv/bin/python -m monitor.run --asof 2026-06-30 # 历史回放：用截至该日的数据出报告
.venv/bin/python -m monitor.run --watchlist config/my_watchlist.yaml # 使用自定义清单
.venv/bin/python -m monitor.scan --watchlist config/my_watchlist.yaml --state 破位下跌 --state 恐慌投降
.venv/bin/python -m monitor.backfill --watchlist config/my_watchlist.yaml # 批量补全缓存
.venv/bin/python -m monitor.watchlist add 000300.SH ak_index 沪深300 A股 # 管理清单
.venv/bin/python scripts/check_crashes.py       # 六案例历史核对（4 崩盘回归 + 2 牛市上半场）
```

每次运行默认同时生成 Markdown / HTML / PDF 三份日报：
- HTML 为带内联 CSS 的单文件（状态语义色、窄屏表格可横滑），适合手机/浏览器查看；
- PDF 由本机无头 Chrome（`/Applications/Google Chrome.app`）从 HTML 转换，A4 带页边距、
  中文用系统字体，不依赖任何 Python PDF 库；未安装 Chrome 时自动降级为只出 MD+HTML 并在终端提示。
- `--watchlist` 生成的报告文件名带清单前缀，如 `reports/my_watchlist-2026-08-01.md`；
  默认 `config/watchlist.yaml` 保持原 `reports/YYYY-MM-DD.{md,html,pdf}` 命名。

数据缓存在 `data/<code>.csv`，增量更新（已有缓存只拉缺失日期）；
单品种拉取失败不中断整体，报告中标注「数据缺失」。

每项含 `code`（缓存文件名）、`name`、`source`（适配器）、`category`；
加品种只需在 yaml 追加一条并确认 source 适配器存在。

source 可选值：
`okx` / `nasdaq` / `naver` / `em_index` / `ak_index` / `ak_sge` / `ak_futures` /
`ak_stock`（A 股） / `ak_etf`（场内 ETF/LOF） / `ak_hk`（港股） / `ak_global_index`（全球指数）。

A 股/ETF/LOF/港股统一使用 akshare 腾讯日线接口（`stock_zh_a_hist_tx`）并做前复权；
全球指数优先 akshare 东方财富全球指数（`index_global_hist_em`），无数据时回退 yfinance。
注：yfinance 在本机网络被 Yahoo 限流（HTTP 429），故海外品种优先使用上述可用源。

## 指标词典（v2：四族 + 八阶段）

> v1（七态「平静→升温→过热→滞涨/分配→破位急跌→恐慌→修复」+ 四指标均分过热分）
> 已废弃，v2 改动：指标按信息源分四族、共线指标同族平均；新增背离/量能结构信号；
> 状态机扩为覆盖完整周期的八阶段。

**四族划分（族内成员各自做 252 日分位，再取均值合成分）**

| 族 | 成员 | 在量什么 |
|---|---|---|
| 趋势位置 Position | BIAS50、BIAS200、回撤分位、MA50/MA200 排列 | 价格相对趋势的绝对位置，高=离开地心引力 |
| 动量 Momentum | RSI(14)、ROC(20)、加速特征（20日涨速−60日匀速、连涨天数） | 涨速与加速度，共线指标同族平均不再重复加权 |
| 波动率 Volatility | ATR%(14)、HV(20)、布林带宽(20,2σ) | 波动的绝对水平与尾部密度 |
| 量能结构 Volume | 成交量 z-score(20) | 放量/缩量程度（无成交量品种整族剔除、剩余权重归一） |

**背离与结构信号（indicators.py 计算，报告「背离标记」列展示）**
- 顶背离⚠：价格创 60 日新高，但 RSI14 低于前一个 60 日新高点的 RSI。
- 底背离✓：价格创 60 日新低，但 RSI14 高于前一个 60 日新低点的 RSI。
- 放量滞涨：vol_z > 1.5 且 |5 日涨幅| < ATR%×5 且处于高位区（回撤 > -15%）。
- 缩量企稳：回撤 < -30% 且近 10 日 vol_z 均值 < 0 且近 10 日未创新低。
- 缩量新高 / 放量破位：v1 保留信号（创新高但 z<0 / 跌破 60 日低点且 z>1.5）。

**打分**
- 四族子分各 0–100，报告中单列（位置/动量/波动/量能），能看到「是哪一族在推高分」。
- 过热分 = max(四族加权, (位置族+动量族)/2)，族权重 位置 0.30/动量 0.30/波动 0.20/量能 0.20；
  取高是为了「波动/量能未确认时不压制位置与动量的极端读数」（缩量阴跌式赶顶也能识别）。
- 恐慌分 = 回撤深度 0.30 + 动量族反向 0.20 + 波动率族 0.20 + 放量下跌 0.15 + RSI 超卖 0.15。
- 所有分位均为品种自身 252 日滚动窗口分位；权重与阈值集中在 `monitor/state.py` 顶部常量。
- 情绪/杠杆族（资金费率、融资余额、VIX）预留接口不接数据：族分缺失时按剩余族权重归一。

## 状态机（v2 八阶段）

`底部盘整 → 启动 → 趋势延续 → 加速/过热 → 高位派筹 → 破位下跌 → 恐慌投降 → 筑底修复 →（回到盘整/启动）`

| 阶段 | 识别逻辑（候选条件） | 行动提示 |
|---|---|---|
| 底部盘整 | 回撤 < -25%，波动率族 < 40 分位，量能萎缩（vol_z 10 日均值 < 0） | 观察，纳入清单 |
| 启动 | 站上 MA50 且 BIAS50 由负转正（30 日内曾为负），动量族 ≥ 45 分位 | 试错建仓区，止损清晰 |
| 趋势延续 | BIAS50 为正，动量族 ≥ 40 分位 | 持有，让利润奔跑 |
| 加速/过热 | (位置+动量)/2 ≥ 80 且在高位区（回撤 > -25%） | 收紧风控，减仓不加仓 |
| 高位派筹 | 近 30 日曾过热（≥90）或（位置 ≥ 65 + 顶背离 + 放量滞涨），且背离/滞涨信号与动量走弱同时成立 | 减仓/离场主窗口 |
| 破位下跌 | 跌破 MA50 且 ROC 分位 ≤ 30 且恐慌分 ≥ 60 | 不接飞刀，执行离场 |
| 恐慌投降 | 恐慌分 ≥ 80 且回撤 < -10%（创新高时的波动毛刺不算恐慌） | 观察，不急于抄底 |
| 筑底修复 | 近 60 日曾恐慌，出现缩量企稳/底背离或波动率回落 | 分批试错，等待启动确认 |

- 切换需连续 2 日确认；「破位下跌」放宽为 1 日；恐慌一日跨越直达时先补记 1 日破位下跌，保证路径完整。
- 迁移带方向约束（ALLOWED_FROM）：如「启动」只能从底部盘整/筑底修复/破位下跌进入，
  「高位派筹」要求曾处加速/趋势或破位后 V 型回高位；不允许的迁移直接忽略，防中间态乱跳。

## 历史核对结论（六案例，scripts/check_crashes.py）

四大崩盘案例（峰值/谷底由程序自动寻找，2024 年以来最大回撤段）+ 两个牛市上半场案例：

| 案例 | 顶部/区间 | 幅度/天数 | 顶部前状态 | 急跌段状态 | 派筹捕捉 | 结论 |
|---|---|---|---|---|---|---|
| BTC-USD | 2025-10-06 → 2026-06-30 | -53.0% / 267天 | 加速/过热（OH 84）+ 派筹 | 破位下跌→恐慌投降（CAP 100） | — | ✓ |
| 白银(AG0) | 2026-01-29 → 2026-07-17 | -56.2% / 169天 | 加速/过热（OH 97）+ 派筹 | 破位下跌→恐慌投降（CAP 99） | — | ✓ |
| 闪迪 SNDK | 2026-06-25 → 2026-07-29 | -56.5% / 34天 | 高位派筹（顶背离+放量滞涨路径） | 破位下跌→恐慌投降（CAP 96） | ✓ | ✓ |
| SK海力士 | 2026-06-22 → 2026-07-30 | -54.7% / 38天 | 加速/过热（OH 92）+ 派筹 | 破位下跌→恐慌投降（CAP 99） | ✓ | ✓ |
| NDX 2023–2024 | 牛市上半场 | — | 趋势延续占比 43%（众数），加速/过热仅 8%（无误报） | — | — | ✓ |
| BTC 2024 年初 | 主升浪 | — | 启动→趋势延续→加速/过热 依次出现 | — | — | ✓ |

核对口径：顶部前 = 峰前 90 个交易日内出现「加速/过热」（过热分 > 80）或「高位派筹」；
急跌段 = 出现「破位下跌」→「恐慌投降」且恐慌分 > 80；派筹识别窗口允许滞后峰顶 10 个交易日
（顶背离+放量滞涨确认需要时间）。NDX 口径：趋势延续占比 ≥ 40% 且加速/过热 ≤ 20%。

v2 调参记录（六案例核对中迭代）：
1. 过热分改为 max(四族加权, 位置+动量组合)——BTC/闪迪的缩量赶顶在纯加权下被波动/量能族稀释到 70 分；
2. 派筹双路径：主路径「近 30 日曾过热 ≥ 90」；短历史品种（闪迪仅 365 行）走替代路径
   「位置 ≥ 65 + 顶背离 + 放量滞涨」（无成交量品种不会走替代路径，NDX 派筹误报从 42% 降到 2%）；
3. 派筹证据要求背离/滞涨信号与动量走弱同时成立（单一动量回落在牛市里 46% 时间都成立，噪声太大）；
4. 恐慌投降加回撤门限 < -10%（白银创新高日的波动毛刺曾让恐慌分虚高）；
5. 方向约束补 V 型恢复通道：启动可从破位下跌进入，派筹可从破位/修复进入（闪迪顶部先破位再回新高）。

最终参数见 `monitor/state.py` 顶部：FAMILY_W = 0.30/0.30/0.20/0.20，T_ACCEL_POSMOM=80，
T_DIST_RECENT_OH=90，T_DIST_POS=65，T_DIST_MOM=60，T_START_MOM=45，T_TREND_MOM=40，
T_PANIC=80，T_BREAKDOWN=60，DD_GATE_PANIC=-10，DD_GATE_OVERHEAT=-25，DD_BOTTOM=-25，T_BOTTOM_VOL=40。

## 目录结构

```
├── config/
│   ├── watchlist.yaml              # 默认品种池
│   ├── my_watchlist.yaml           # 用户自定义清单
│   └── my_watchlist_unresolved.yaml # 未上市/数据不足品种待确认
├── monitor/
│   ├── data.py             # 多数据源适配器 + CSV 增量缓存
│   ├── indicators.py       # 四层指标 + 布林带宽 + 背离/量能结构信号（纯 pandas）
│   ├── state.py            # 四族分位归一、双打分、八阶段状态机（权重/阈值在顶部）
│   ├── report.py           # MD/HTML 日报渲染 + 无头 Chrome 转 PDF
│   ├── run.py              # CLI 入口（--watchlist/--asof/--symbol/--format）
│   ├── scan.py             # 按状态扫描清单
│   ├── backfill.py         # 批量补全日线缓存
│   └── watchlist.py        # 管理观察清单
├── scripts/check_crashes.py# 六案例历史核对（4 崩盘 + 2 牛市上半场）
├── data/                   # 日线缓存
└── reports/                # 每日报告（md/html/pdf）+ latest_state.json（状态切换对比用）
```

## 边界

- 只做状态提示，不做仓位/买卖建议、不接实盘。
- 推送（Bark/企业微信）与杠杆/情绪数据源（资金费率、融资余额、VIX）预留不做实现。
